01 — Einordnung

Wo Klarsatz steht.

Sprachen für Anfänger gibt es seit den Sechzigerjahren. Sie unterscheiden sich weniger darin, was sie für richtig halten, als darin, welche Hürde sie wegnehmen.

Klarsatz steht in einer langen Tradition von Lernsprachen. Logo, Niki, Robot Karol und Guido van Robot haben lange vorher versucht, Anfänger nicht sofort mit der vollen Komplexität einer etablierten Sprache zu konfrontieren. Die Ansätze setzen dabei an unterschiedlichen Stellen an — und keiner davon ist der richtige für alle.

Projekt Form Sprache Schwerpunkt Weiterführung
LogoProgrammieren als Werkzeug zum Denken und Experimentieren, bekannt durch die Turtle-Grafik. Seymour Papert, ab 1967. Text je nach Variante Denken und Ausprobieren unterschiedlich
Niki, der RoboterDeutsche Fassung der Minisprache Karel (Richard E. Pattis, 1981): ein Roboter in einem Gitter aus Straßen, gedacht als Vorbereitung auf Pascal. Text deutsch Algorithmen in einer kleinen Welt Pascal
Robot KarolDeutschsprachige Lernumgebung mit Roboterwelt und Aufgaben, gebaut, um Schüler an die Algorithmik heranzuführen. Seit 2001 von Ulli Freiberger gepflegt, ein direkter Abkömmling von Karel. Text, dazu eine Blockansicht deutsch Algorithmen in einer kleinen Welt nicht festgelegt
ScratchVisuelle Programmierung mit Blöcken. Syntaxfehler werden weitgehend vermieden, die Struktur des Programms wird räumlich sichtbar. Blöcke übersetzte Oberfläche, wenig Text Struktur sichtbar machen verschiedene Wege
Guido van RobotDieselbe Spielidee wie Niki, aber mit einer an Python angelehnten Schreibweise — benannt nach Guido van Rossum und ausdrücklich als Vorbereitung auf Python gedacht. Text an Python angelehnt, englisch Algorithmen in einer kleinen Welt Python

Welche Hürde jeweils kleiner wird

Die Unterschiede liegen weniger darin, was „richtig“ oder „falsch“ ist, sondern darin, welche Einstiegshürde ein Ansatz zuerst wegräumt.

Scratch

Die Syntax fällt weitgehend weg. Programmiert wird mit Blöcken, die gar nicht falsch zusammenpassen können.

Robot Karol, Niki, Logo

Die Welt wird kleiner. In einer überschaubaren Lernwelt zeigt sich der Algorithmus, bevor die Sprache groß wird.

Python

Nichts wird reduziert. Man arbeitet von Anfang an mit einer vollständigen Sprache und ihrem echten Ökosystem.

Klarsatz

Die Sprachhürde wird kleiner. Die Welt bleibt textuell, die Programme bleiben echte Programme — weg fällt zunächst die fremde Sprach- und Symbolhürde.

Das ist die Annahme hinter Klarsatz, kein nachgewiesener Vorteil: dass sich die sprachliche Hürde trennen lässt von dem, was beim Programmieren tatsächlich schwer ist.

Weder Blöcke noch Python ersetzen.Klarsatz versucht nicht, Programmieren durch Blöcke zu ersetzen, und auch nicht, Python zu ersetzen. Der Ansatz liegt dazwischen: echter Quelltext von Anfang an, aber mit einer vertrauten sprachlichen Oberfläche.

Was Klarsatz anders macht

Die interessante Frage ist deshalb nicht, ob Klarsatz Python oder Scratch ersetzt. Das soll es nicht. Die Frage lautet, ob ein textbasierter Einstieg in vertrauter Sprache eine sinnvolle Brücke zwischen visueller Programmierung und etablierten Programmiersprachen sein kann.

Das ist letztlich eine empirische Frage, und sie ist offen: Verstehen Anfänger die Konzepte damit schneller oder haltbarer? Wie erleben sie Fehler, wenn die Meldung in ihrer eigenen Sprache steht? Und wie gut gelingt danach der Übergang zu Python? Belastbar beantworten lässt sich das nur im Unterricht, nicht auf einer Webseite.

Kein Endpunkt. Ein erster Schritt.Wer mit Klarsatz anfängt, soll weiterziehen — das ist der ganze Zweck.
