Spielplatz

Schreiben, laufen lassen, zusehen.

Wähle oben links ein Beispiel — oder Leeres Blatt, um selbst zu schreiben — und drücke Strg+Enter. Prüfen findet Fehler, ohne das Programm auszuführen, Formatieren rückt es sauber ein, und Als Python zeigt dasselbe Programm in Python. Fragt ein Programm etwas, erscheint unter der Ausgabe ein Eingabefeld; zeichnet es, erscheint eine Leinwand.

Die Spielwiese wird geladen — beim ersten Mal dauert das einen Moment, weil der Interpreter samt Python in deinen Browser geladen wird (rund 14 MB, danach zwischengespeichert).

Sicher ausprobieren

Was hier nicht passieren kann.

Der Spielplatz führt den echten Klarsatz-Interpreter aus — als Python im Browser, nicht auf dem Server.

Kein Dateizugriff

Der Spielplatz läuft ohne Dateisystem: Lies und Schreibe arbeiten auf einem Speicherbereich, der mit dem Lauf verschwindet. Auf keine Festplatte wird geschrieben — weder auf deine noch auf den Server.

Nichts wird gesendet

Dein Quelltext bleibt im Browser. Es gibt keinen Server, der Programme ausführt, und auch die Python-Laufzeit kommt von dieser Seite selbst — kein fremder Dienst sieht, was du schreibst.

Abgeschotteter Lauf

Jedes Programm läuft in einem eigenen Hintergrundprozess des Browsers, ohne Zugriff auf diese Seite. Hängt ein Lauf, wird der Prozess beendet und neu gestartet — die Seite bleibt bedienbar.

Begrenzte Mittel

Schritte, Laufzeit, Textlängen, Listengrößen, Zahlengrößen und Verschachtelungstiefe sind begrenzt. Endlosschleifen enden von allein, und kein Programm kann den Browser vollschreiben.

Trotzdem ehrlich gesagt: Klarsatz ist ein Lernprojekt, kein gehärteter Dienst. Die Einzelheiten stehen in der Referenz.

Die Brücke

Dasselbe Programm in Python.

Der Knopf Als Python übersetzt, was im Editor steht — damit der Schritt in eine verbreitete Sprache kein Sprung ins Kalte ist.

Klarsatz
Merke 5 als Zahl.
Zähle von 1 bis 3 mit i:
    Zeige i mal Zahl.
Ende.

Python

Zahl = 5
for i in range(1, 3 + 1):
    print((i * Zahl))

Die Übersetzung ist auf Lesbarkeit aus, nicht auf Gleichheit bis ins letzte Zeichen. Wo Klarsatz anders rechnet — Listen ab 1, Kommazahlen mit Komma, ganzzahliges Teilen — schreibt sie einen Hinweis in den Kopf des erzeugten Programms, statt eine Hilfsbibliothek mitzuschleppen. Auf der Kommandozeile macht das python3 -m klarsatz --nach-python programm.klar.

Am eigenen Rechner

Klarsatz lokal laufen lassen.

Der Interpreter ist reines Python 3 ohne weitere Abhängigkeiten — auf dem Raspberry Pi genauso wie auf dem Schreibtisch.

python3 -m klarsatz programme/03_taschenrechner.klar   # Programm ausführen
python3 -m klarsatz                                    # interaktive Konsole
python3 -m klarsatz --pruefe programm.klar             # Fehler finden, ohne auszuführen
python3 -m klarsatz --formatiere --ersetzen programm.klar

Dort stehen auch Lies und Schreibe offen — standardmäßig auf den Arbeitsordner beschränkt.
